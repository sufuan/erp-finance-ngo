# TPDA e-Sheba

Microfinance & NGO management suite for **Talgachi Poor Development Association (T.P.D.A.)** — তালগাছী দরিদ্র উন্নয়ন সংস্থা (NGO, Reg. সিরাজ/৫৮৫/সমাজসেবা/২০০০).

## Stack

- PHP 8.4 · Laravel 13 · Inertia.js + React · Tailwind CSS
- MySQL 8.4 LTS · Redis
- Flutter field-worker app — **TPDA e-Sheba** (offline-first collections, duty-hours GPS tracking)
- Member self-service portal · Full Bangla + English i18n

## Status

Under active development. First milestone: **Steps 0–5** — project scaffold, core infrastructure (branches, business day, append-only audit), RBAC (Spatie), dynamic settings, accounting core (double-entry posting engine), geographic masters, and HR masters.

The project is built step-by-step from a 47-unit build plan; each step is committed separately after passing its tests. Full setup instructions land with Step 0.
